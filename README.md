# hiimchinh.com

Blog and portfolio of Chinh Hoang. Built with [Astro](https://astro.build) on the
[AstroPaper](https://github.com/satnaing/astro-paper) theme (MIT), hosted on
Cloudflare Workers.

```sh
corepack enable
pnpm install
pnpm dev
```

Writing, testing and deploying: see [AGENTS.md](AGENTS.md).
